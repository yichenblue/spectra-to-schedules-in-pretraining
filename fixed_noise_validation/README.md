# Fixed-noise deterministic-equivalent snapshot

This directory is a publication-safe subset of the accepted support-adaptive deterministic-equivalent Volterra validation campaign. It contains the seven width-grid curve tables, completion/convergence manifests, terminal plateaus needed by the early-stopping analysis, and the four plotting modules used by the paper.

The source curves cover widths 10 through 51,200 and noise variances 0, 0.1, 1, and 10 across the seven legacy phase labels. The plotting code maps the relevant labels to the current FB/LM/IM taxonomy used by the manuscript.

Absolute paths recorded by the original compute environment have been replaced with `SOURCE_SNAPSHOT/<filename>` labels. Numerical values and gate outcomes are unchanged.
